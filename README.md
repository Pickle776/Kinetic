# Kinetic

**Kinetic** is a lightning-fast, real-time multiplayer card game. 

## The Origin
For the record: this game is based on actual **Californian Speed**. It was renamed to "Kinetic" to clearly differentiate it from standard "Speed" (and to avoid the endless confusion with people who mistakenly call normal Speed "Californian Speed"—they are completely different games).

## Current State
The project is currently in active development and playable in its core form.
* **LAN Multiplayer:** Fully functional for local network play.
* **Smart Bots:** Built-in AI opponents utilizing a custom state machine for offline practice.
* **Core Engine:** Fast-paced mechanics including clash windows, penalty timers, and "stuck" board scoop resolutions are fully implemented.

## The Idealized Shape
The final vision for Kinetic transforms it into a fully-fledged competitive platform, including:
* Seamless **Online Multiplayer** with global matchmaking.
* Highly optimized, lag-compensated netcode to handle sub-second, simultaneous card placements.
* A polished competitive ranking system and leaderboard.
